# 도둑잡기 V3 (최대 6인 / AI / 싱글)

첨부된 `조커 카드.aseprite`의 추출 이미지 42장을 `public/cards/`에 포함했습니다.

## 규칙
- 최소 2자리, 최대 6자리. 인간 플레이어 1~6명, 나머지는 대기실에서 방장이 AI로 추가·제거합니다.
- 한 판에 각 숫자당 무작위 2장씩 총 26장과 조커 1장으로 구성합니다.
- 같은 숫자는 무늬와 관계없이 두 장씩 제거하며, 턴을 가진 사람이 다음으로 카드가 남아 있는 사람의 손에서 한 장을 뽑습니다.
- 카드가 0장이 되면 자동 탈출하며 마지막까지 조커가 남은 사람이 패배합니다. 나머지는 카드가 소진된 순서대로 순위가 기록됩니다.
- 기록은 해당 방의 참여 좌석에 유지되며 서버 재시작 이후에는 초기화됩니다.

## 설치 없이 플레이하기
Render 같은 웹 서버에 배포하면 플레이어 컴퓨터에는 설치가 전혀 필요 없습니다. 직접 서버를 구동할 경우 서버 관리자만 Python 3.10+ 필요:

```bash
pip install -r requirements.txt
python server.py
```

브라우저에서 `http://localhost:8080` 접속. 방 생성 후 AI 추가로 싱글 가능. 같은 네트워크 외부 친구와 하려면 서버를 공개 주소로 배포해야 합니다.

## Render 배포
GitHub 저장소에 프로젝트 업로드 후 Render의 New > Blueprint로 `render.yaml`을 선택하거나 Web Service의 Python 런타임에 빌드 명령 `pip install -r requirements.txt`, 시작 명령 `python server.py`를 지정합니다. `PORT`는 플랫폼이 제공합니다.

## 주의
- 인메모리 방: 서버 재시작 시 방과 기록 초기화
- 재접속: 같은 브라우저 탭의 세션을 활용
- 최소 2자리만 있으면 시작 가능; 4인도 가능; 6인까지 지원
- 게임 서버가 카드와 짝 제거를 판정, AI도 서버에서 행동
